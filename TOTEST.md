# TOTEST — сделано, но не проверено

Сюда попадает задача, **реализованная воркером**, но ещё не прошедшая полную
проверку. Пока задача здесь — она не закрыта.

## Правила

1. Сюда переносит **только оркестратор**, и **только при наличии коммита**.
   Нет коммита — задача остаётся в `TODO.md`.
2. Воркер сюда ничего не пишет. Его зона: код, тесты, `functions/`,
   `hermes-home/`.
3. Проверка определяется автоматически: полный локальный прогон набора на
   сервере **плюс** зелёный бейдж GitHub Actions на запушенном коммите.
   Оба зелёные → задача уходит в `PASSED.md`.
4. Если проверка упала, задача возвращается в `TODO.md` как **точечная починка**,
   в тексте которой назван конкретный упавший тест. Реализовывать заново нельзя.
5. Оркестратор не имеет права писать итог в `NOTES.md`, пока не сдал этот файл.

## <дата> — реализовано: <что> (`<коммит>`)
