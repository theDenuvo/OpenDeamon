# Capability Matrix — что уже есть и чем это решается

Задача: чтобы ядро **не изобретало то, что уже есть**. Ориентир — инцидент с
изображением, где веб-API был выбран при живом локальном GPU, а готовый
`stable-diffusion` лежал в хабе.

Это **не роутер**. Роутер выбирает за ядро и отнимает у него пути решения.
Здесь только факты: «вот чем это уже делается». Решение остаётся за моделью.

## Как читать

- **Локально** — уже установлено на машине, работает без сети и квоты. Первый выбор.
- **Хаб** — скилл существует в Skills Hub (101 156 записей), его надо
  `hermes skills install <identifier>`.
- **Есть встроенное** — из 51 builtin-скилла Hermes.
- **Построить** — только если ничего выше нет.

Если задачи нет в таблице: сначала `skill_finder`, потом решение ядра.

## Правило приоритета

```
локально установленное  →  Skill Hub  →  GitHub  →  веб-сервис  →  построить самому
```

**Жёсткое исключение.** Если задача креативного класса (image / video /
tts / ocr / diffusion / upscale / 3d) и на машине есть GPU — локально
выигрывает у любого веб-сервиса, без обсуждения. `skill_finder` печатает
`!! PREFER LOCAL` с именем GPU и VRAM.

Почему исключение жёсткое: веб-сервисы этого класса заметно ниже по
качеству и тратят квоту. Пример: веб отдал 2 байта и был засчитан как
успех, локальный GPU дал 385 KB корректной картинки за 1.5 с.

## Чего в таблице нет (и почему)

- **Транскрипт аудио локально** — не развёрнуто. Нужен `faster-whisper` +
  веса ~3 ГБ (модель `Systran/faster-whisper-large-v3`). Проверено
  2026-09-30: ни `faster_whisper` в `venvs/img` или `venvs/ComfyUI`, ни
  whisper-репозитория в HF-кэше нет. GPU есть, так что разворачивается
  легко — сделаем по реальному запросу, а не заранее.
- **Видео/аудио-генерация** — карта есть, но локальной модели не
  развёрнуто. Статус: хаб. Ставить только по реальному запросу.
- **Поиск по локальным файлам** — `search_files` покрывает.
- **`autonomous_tools`** — интерфейс объявлен, реализации нет. Не
  рассчитывать на него как на рабочую функцию.

## Как эта таблица проверялась

Каждая строка со словом «локально» проверена на диске, а не взята из
замысла. Раньше здесь стояло «Транскрипт аудио — локально:
faster-whisper-large-v3 в кэше», чего никогда не было: это была моя
ошибка, я записал предположение как факт. Отсюда правило: **строка
«локально» считается неподтверждённой, пока пакет не найден на диске и
модель не лежит в кэше.**

## Обновление

Новый скилл из хаба → одна строка в таблицу + строка в его `SKILL.md`
(cost / verify / quality floor). Таблица и скилл должны говорить одно и то же,
иначе расходимся.
