# NOTES — короткие заметки оркестратора для планировщика

Пишет **только оркестратор**, только по факту свершившегося. Это единственный
файл, который планировщик читает, чтобы знать текущее состояние проекта, не
перечитывая `TODO.md` целиком.

## Правила

1. Одна строка на событие. Не пересказывать `TODO.md`, не рассуждать.
2. Только то, что уже случилось и подтверждено: коммит, зелёная проверка,
   падение проверки, задача без коммита.
3. Ограниченная длина — файл не растёт бесконечно, старые записи сворачиваются.
4. Итог разрешено писать **только после того, как сдан `TOTEST.md`**.

Формат: `HH:MM — что произошло — чем подтверждено`
